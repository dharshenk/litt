# Task 05 report: integration

- Root `npm run build` creates the web bundle. `npm start` serves it in production, with SPA fallback for `/` and `/r/:code`; production refuses to start without Discord client id, client secret, and session secret.

## Manual play-test checklist

1. Run `npm install` and `npm run dev`; open `http://localhost:5173` in six tabs.
2. Set a unique Dev login name in each tab; create a room in one and join through its invite link in the others.
3. Assign three players to each team, leave the timer off, select award mode, and start.
4. Play asks, failed asks, correct declarations and choose phases; confirm only your cards appear under “Your hand”.
5. Reload a seated player during the game and confirm their seat and hand return.
6. Complete the game, confirm scores and stats, then try a host rematch.
7. For Discord login, configure the credentials and callback URI in `.env`; for production, build first and start with `NODE_ENV=production`.
